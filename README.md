# VRS Kitchen & Bar

Next.js 15 + React 19 + Tailwind CSS demo for a fictional East LA restaurant.

## Features
- Hero, featured dishes, full menu with category filtering
- Mock ordering tray with quantity controls
- AI dietary guide (client-side mock)
- Table session demo with QR code
- Mobile tab bar, sticky header, toast notifications
- Sign-in panel (guest/staff/admin demo modes)

## Development
```bash
npm run dev
```
Opens at http://localhost:3000
